# Contributing to Sandbox Migration Shield

Thank you for considering contributing! This document provides guidelines.

## How to Contribute

### Reporting Bugs
1. Check [existing issues](https://github.com/vladarchitectservicenow-oss/sandbox-migration-shield/issues)
2. Use the Bug Report template
3. Include: ServiceNow version, shield version, steps to reproduce, expected vs actual

### Pull Requests
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Write tests for your changes
4. Ensure all tests pass
5. Update documentation if applicable
6. Commit with descriptive messages in English
7. Push and open a PR against `main`

### Code Style
- All code, comments, and commit messages in English
- Copyright header required on all source files:
  ```
  Copyright (c) 2026 Vladimir Kapustin
  SPDX-License-Identifier: AGPL-3.0-only
  ```

### Testing Requirements
- All new features require tests
- Bug fixes require a regression test
- Target: 90%+ code coverage for new code
